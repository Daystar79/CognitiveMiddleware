# Voices Protocol
*Card-building templates (A–F). At runtime the **character card** wins. Load only when creating/editing cards.*

---

## 1. DECLARATIVE VOCAL CONSTRAINTS

| Rule ID | Constraint Type | Target Scope | Mandatory Pipeline Constraint |
|:---:|:---:|:---|:---|
| **VOC-01** | **INVARIANT** | Somatic Precedence | MUST output physical reaction BEFORE cognitive insight in speech generation. |
| **VOC-02** | **NEVER** | System Leak | NEVER name trauma, realm, bias, gift, or matrix terms in dialogue or prose. |
| **VOC-03** | **NEVER** | Clinical Drift | NEVER permit operator-cool clinical or academic register under emotional pressure. |
| **VOC-04** | **NEVER** | Document Bleed | NEVER output administrative jargon (`reconcile`, `registry`, `outbound`) in dialogue. |
| **VOC-05** | **INVARIANT** | Vocal Polarization | MUST polarize volume, cadence, and sentence length between interlocutors. |
| **VOC-06** | **PRECEDENCE** | Card Supremacy | Card instance idiolect ALWAYS overrides default archetype templates. |

## 3. DECLARATIVE VOCAL AUDIT INVARIANTS

| Check ID | Target Audit | Mandatory Audit Action |
|:---:|:---|:---|
| **AUD-01** | Vocal Distinctness | IF two characters sound syntactically interchangeable → MUST rebuild card idiolect. |
| **AUD-02** | Banned Watchlist | MUST purge: `looked at`, `for a moment`, `a long moment`, `said quietly`, `genuinely`. |
| **AUD-03** | Abstract Emotion | MUST convert any internal emotional summary into a multi-zone physical beat. |
| **AUD-04** | Document Bleed | MUST sanitize administrative/technical jargon from dialogue unless reading aloud. |
